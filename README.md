# 🚀 Smart Failure Detection System

## Overview

Smart Failure Detection System is an AI-powered web application that helps entrepreneurs evaluate startup ideas before implementation. The application analyzes market conditions, competitor information, business risks, and generates AI-powered recommendations to support better business decisions.

The application is built using React, Node.js, Express.js, PostgreSQL (Neon), and the Groq AI API.

---

## Features

### 📌 Project Submission
- Submit startup information
- Industry selection
- Business model selection
- Budget estimation
- Target market
- Project description

### 📊 Market Analysis
- Market growth analysis
- TAM, SAM and SOM visualization
- Market opportunity score
- Market trend charts
- AI-generated market insights

### 🏢 Competitor Analysis
- Competitor comparison table
- Competition level
- Market share visualization
- Competitor score charts
- AI competitor analysis
